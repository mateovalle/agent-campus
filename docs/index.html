AGENT CAMPUS

Your Claude Code agents, working in a pixel office.

An open-source mission-control desktop app. Every project is an office on one campus map; every agent is a character you can watch think, code, and ask for permission.

ONE DAY WITH A TEAM OF AGENTS

Real Claude Code sessions — same login, same config, same transcripts. Start in the app, resume in your terminal, or vice versa.

You have six terminals open.

One of them is waiting on you and you don't know which. One finished ten minutes ago. One has been stuck on a permission prompt since you went to get coffee. You alt-tab through all six to find out.

Open Agent Campus and the same day looks like this.

Every project gets an office.

Your folders become rooms on one map. Who is working, who is stuck, and what each project has cost today — all of it readable without opening anything.

You hire someone.

Click an office, click + Agent, and a character walks in and sits down at a free desk. Behind the sprite it is an ordinary Claude Code session: your login, your config, a transcript you can pick up in a terminal later.

You hand over the backlog.

One board across every office. Press Assign on a task and an agent spawns to do it — and if the task is tagged [qa] or [marketing], it spawns with that charter, that tool policy and that character skin. The review roles cannot edit at all, so a [security] task comes back as a verdict rather than a silent fix.

You can tell who is blocked from across the campus.

Claude Code always asks before it writes. What changes here is how you find out: an amber bubble goes up over that character's head and they move into the board's Needs You column, with the buttons to unblock them. You read it off the map instead of alt-tabbing to look.

You see exactly what it cost.

Not an estimate — the number the SDK reports, per turn, per day and per project, sitting on each office label.

They work while you're asleep.

Schedules run daily, weekly, or every few minutes, and they fire with the window closed. Whatever was missed while the app was off is offered to you in the morning, to run or to skip.

And then you make the place yours.
